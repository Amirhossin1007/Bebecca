صفحه **Errors** مشکلات فعلی پنل و نودها را بر اساس شدت فهرست می‌کند. وقتی چیزی کار نمی‌کند، اول اینجا را بررسی کن. این صفحه کامل‌تر از داشبورد است، چون داشبورد فقط خطاهای بحرانی را نشان می‌دهد که یک سرویس را متوقف می‌کنند.

## سطوح شدت

| سطح | معنی |
| --- | --- |
| **Critical** | خطایی که یک سرویس را متوقف می‌کند. خطاهای بحرانی روی داشبورد هم نمایش داده می‌شوند. |
| **Error** | یک عملیات ناموفق یا جزء خراب که نیاز به اقدام دارد. |
| **Warning** | وضعیتی که ممکن است بعداً مشکل ایجاد کند. |

با **Filter by severity** یک سطح یا همه سطح‌ها را نشان بده. برای بارگذاری وضعیت فعلی روی **Refresh** بزن.

## منبع مشکل‌ها

هر مشکل منبع خودش را نشان می‌دهد تا بدانی کدام بخش را باز کنی:

- **Inbound** و **Host** مشکل‌های اینباند و هاست را نشان می‌دهند. برای نمونه، هاستی ممکن است به اینباندی اشاره کند که در پیکربندی ذخیره‌شده Xray وجود ندارد.
- **Xray configuration** و **Outbound / proxy service** خطاهای پیکربندی و سرویس‌های پروکسی را نشان می‌دهند.
- **Node**، **Node synchronization** و **Native node service** اتصال نود، عملیات در انتظار و سرویس‌های اجراشده روی نود را نشان می‌دهند.
- **Server resources** مشکل‌های منابع سرور را نشان می‌دهد.
- **TLS certificate** گواهی‌های منقضی یا با تنظیم نادرست را نشان می‌دهد. راهنما: [گواهی‌های SSL](../ssl-certificates/).
- **HAProxy**، **Hosted application / bot**، **Outbound subscription**، **Telegram**، **Backup**، **Webhook** و **Database** خطاهای هر بخش را نشان می‌دهند.
- **Recent runtime warning** و **Recent runtime error** پیام‌های ۱۵ دقیقه اخیر را فهرست می‌کنند.

## رفع مشکل‌ها

1. ابتدا روی **Critical** فیلتر کن و اول همان‌ها را رفع کن.
2. روی **Open section** کنار یک مشکل بزن تا مستقیم به صفحه‌ای بروی که آن را کنترل می‌کند.
3. هر بار یک تغییر بده، بعد روی **Refresh** بزن تا مطمئن شوی مشکل رفع شده است.
4. برای باز کردن فهرست طولانی از **Show all problems** و برای جمع کردن آن از **Show fewer** استفاده کن.

درخواست‌های ناموفق از نشست مرورگر فعلی وقتی نمایش داده می‌شوند که فیلتر روی همه سطح‌ها یا **Error** باشد. این خطاها از درخواست‌های خود پنل می‌آیند، نه از خود سیستم.

{{< callout type="info" >}}
مشکلی که بعد از رفع دوباره برمی‌گردد معمولاً علت دوم دارد. منابع مرتبط مثل نودی را که اینباند روی آن است بررسی کن و دوباره Refresh بزن.
