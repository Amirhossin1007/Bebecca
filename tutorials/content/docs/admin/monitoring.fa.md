سه صفحه نشان می‌دهند پنل چطور استفاده می‌شود و اخیراً چه چیزی تغییر کرده است: Usage، Live Connections و Recent Actions.

## مصرف

<p class="rb-panel-actions"><a class="rb-panel-button" href="#" data-panel-route="/usage">باز کردن Usage</a></p>

- بین تب‌های **Admins**، **Nodes** و **Services** جابه‌جا شو تا مصرف هر گروه را ببینی.
- **Selected range total** مجموع ترافیک بازه‌ای را که انتخاب کرده‌ای نشان می‌دهد.
- نمایش مصرف به ثبت آن بستگی دارد. اگر ثبت مصرف نود یا کاربر در [تنظیمات](../../settings/) خاموش باشد، صفحه این را نشان می‌دهد و تاریخچه جدیدی ثبت نمی‌کند.

## اتصال‌های زنده

<p class="rb-panel-actions"><a class="rb-panel-button" href="#" data-panel-route="/access-insights">باز کردن Live Connections</a></p>

Live Connections کاربران فعال را در Xray، OpenVPN، WireGuard، L2TP، IKEv2 و Cisco AnyConnect فهرست می‌کند. اتصال‌های اخیر با داده‌های geosite و geoip گروه‌بندی می‌شوند تا ببینی کاربران به چه پلتفرم‌هایی وصل می‌شوند. قبل از تغییر کاربر یا هاستی که به نظر در حال استفاده است، این صفحه را بررسی کن.

## اقدامات اخیر

<p class="rb-panel-actions"><a class="rb-panel-button" href="#" data-panel-route="/recent-actions">باز کردن Recent Actions</a></p>

Recent Actions تغییرات ادمین‌ها را ثبت می‌کند. برای هر مورد می‌بینی چه کسی تغییر را انجام داده، کدام منابع تحت تأثیر بوده‌اند و یک پیش‌نمایش تغییر با مقادیر **Before** و **After** وجود دارد.

Rollback وضعیت قبل از یک اقدام را برمی‌گرداند. هر اقدام یکی از این وضعیت‌ها را دارد:

| وضعیت | معنی |
| --- | --- |
| **Rollback available** | وضعیت قبلی هم‌اکنون قابل بازگردانی است. |
| **Rolled back** | این اقدام قبلاً برگردانده شده است. |
| **Expired** | snapshot بازگردانی خیلی قدیمی شده است. فقط متادیتا باقی مانده است. |
| **Conflict** | تغییر جدیدتری همان منابع را لمس کرده، پس بازگردانی متوقف شده است. |
| **History only** | این اقدام فقط برای تاریخچه ثبت شده و قابل بازگردانی نیست. |

{{< callout type="warning" >}}
قبل از rollback، پیش‌نمایش تغییر و فهرست مسیرهای تغییرکرده را بررسی کن. اگر تعارضی وجود داشته باشد، بازگردانی متوقف می‌شود و تغییر جدیدتر را بازنویسی نمی‌کند.
{{< /callout >}}
