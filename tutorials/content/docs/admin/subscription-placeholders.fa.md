پیام‌های جایگزین اشتراک، وقتی اشتراکی دیگر قابل استفاده نیست، جزئیات واقعی اتصال را با یک پیام کوتاه عوض می‌کنند: اشتراک منقضی شده، به سقف حجم رسیده یا به‌صورت دستی غیرفعال شده است. کلاینت همچنان یک اشتراک معتبر دریافت می‌کند و پیام توضیح می‌دهد چرا اتصال متوقف شده است.

## ساختار تنظیمات

- **Service defaults** برای هر سرویس، برای همه ادمین‌هایی که از آن استفاده می‌کنند اعمال می‌شود.
- هر ادمین می‌تواند **Use the service default** را نگه دارد، یا آن را خاموش کند تا پیام‌های متفاوتی فقط برای همان ادمین و سرویس تنظیم کند.
- پیام‌های جایگزین فقط روی کاربران غیرفعال متعلق به آن ادمین در آن سرویس اثر می‌گذارند. کاربران فعال تغییر نمی‌کنند.
- قبل از تنظیم پیام‌ها، حداقل یک سرویس به ادمین اختصاص بده.

## پیام‌ها

هر وضعیت پیام جدا دارد:

- **Expired subscription message** برای اشتراک‌هایی است که از تاریخ انقضا گذشته‌اند.
- **Traffic limit message** برای اشتراک‌هایی است که همه حجم خود را مصرف کرده‌اند.
- **Disabled subscription message** برای اشتراک‌هایی است که به‌صورت دستی غیرفعال شده‌اند.

برای فعال‌شدن پیام‌ها روی یک سرویس، **Use placeholders for this service** را روشن کن.

## متغیرها

این متغیرها وقتی اشتراک باز می‌شود با مقادیر فعلی کاربر جایگزین می‌شوند:

| متغیر | جایگزین می‌شود با |
| --- | --- |
| `{USERNAME}` | نام کاربری. |
| `{STATUS_TEXT}` | وضعیت فعلی به‌صورت متن. |
| `{DATA_USAGE}` | حجمی که کاربر مصرف کرده است. |
| `{DATA_LIMIT}` | سقف حجم کاربر. |
| `{EXPIRE_DATE}` | تاریخ انقضای کاربر. |

بعد از هر تغییر **Save changes** را بزن. برای بررسی نتیجه، لینک اشتراک یکی از کاربران تحت تأثیر را در مرورگر یا کلاینت باز کن.
