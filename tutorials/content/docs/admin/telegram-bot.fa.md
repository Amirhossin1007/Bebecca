ربات تلگرام ربکا به ادمین‌ها دسترسی سریع به کاربران، مصرف و وضعیت سیستم می‌دهد. همچنین می‌تواند اعلان‌های عملیاتی را به چت‌هایی که انتخاب می‌کنی بفرستد. بکاپ زمان‌بندی‌شده جدا از این بخش تنظیم می‌شود؛ راهنمای آن را در [فعال‌سازی بکاپ تلگرام](../telegram-backup/) ببین.

## قبل از شروع

- با BotFather یک ربات بساز و توکن آن را محرمانه نگه دار. هر کس توکن را داشته باشد می‌تواند ربات را کنترل کند.
- شناسه عددی هر چتی را که باید از ربات استفاده کند پیدا کن. شناسه گروه‌ها و کانال‌ها معمولاً عدد منفی است.
- ربات فقط به چت‌هایی جواب می‌دهد که در **Admin Chat IDs** آمده‌اند. پیام یا دکمه از چت‌های دیگر نادیده گرفته می‌شود.

## اتصال ربات

1. **Bot API Token** را در تب Telegram وارد کن.
2. یک یا چند **Admin Chat IDs** عددی را وارد کن و با کاما از هم جدا کن.
3. گزینه **Enable Telegram bot** را روشن کن. بعداً می‌توانی آن را خاموش کنی بدون اینکه توکن پاک شود.
4. فقط اگر سرور پنل به تلگرام دسترسی مستقیم ندارد، **Proxy URL** را تنظیم کن.
5. دکمه مشترک **Save Settings** را بزن، بعد **Send test message** را بزن.

{{< callout type="info" >}}
همه تب‌ها از یک دکمه **Save Settings** استفاده می‌کنند. قبل از تست، تغییرات را ذخیره کن تا تست با توکن و شناسه‌های فعلی انجام شود.
{{< /callout >}}

## ارسال رویدادها به مقصد درست

- **Logs Chat ID** پیام‌های خطا و گزارش‌ها را می‌گیرد. شناسه عددی گروه یا کانال مقصد را وارد کن. اگر خالی بماند، از چت‌های ادمین استفاده می‌شود.
- اگر مقصد فوروم است، گزینه **Logs chat is a forum** را روشن کن و **Topic ID** را وارد کن. اگر تاپیک ID خالی باشد، ربات خودش تاپیک را می‌سازد.
- برای چت بکاپ هم همین گزینه‌های فوروم در تنظیمات بکاپ وجود دارند.

## انتخاب رویدادها

تب Telegram رویدادها را گروه‌بندی می‌کند تا فقط آنچه نیاز به توجه دارد را فعال کنی:

| گروه | نمونه‌ها |
| --- | --- |
| رویدادهای کاربر | ساخته‌شدن، ویرایش یا حذف کاربر؛ تغییر وضعیت؛ ریست مصرف؛ لغو اشتراک؛ تنظیم یا اعمال تمدید خودکار. |
| رویدادهای ادمین | ساخته‌شدن، ویرایش یا حذف ادمین؛ ریست مصرف ادمین؛ رسیدن به محدودیت حجم یا تعداد کاربر. |
| رویدادهای نود | ساخته‌شدن یا حذف نود؛ اتصال، در حال اتصال، غیرفعال، محدود یا خطادار شدن نود؛ ریست مصرف نود؛ گزارش خطای نود. |
| رویدادهای ورود | تلاش‌های ورود ادمین‌ها. |
| رویدادهای خطا | خطاهایی که سیستم گزارش می‌کند. |

اگر همه رویدادها به یک چت برود، هشدار واقعی به سادگی دیده نمی‌شود. فعالیت روزمره کاربران را در یک چت نگه دار و هشدارهای نود و خطا را به چتی بفرست که کسی به‌طور مرتب آن را می‌بیند.

## دستورهای ربات

این دستورها را از یک چت مجاز بفرست:

| دستور | نتیجه |
| --- | --- |
| `/user <username>` | نمایش یک کاربر و گزینه‌های مدیریت آن. |
| `/usage <username>` | نمایش مصرف یک کاربر. |
| `/system` | نمایش وضعیت سیستم. |
| `/help` | فهرست دستورها. `/start` همین راهنما را نشان می‌دهد. |

ربات منوی اصلی هم دارد و بعضی کارها ممکن است یک سؤال تکمیلی بپرسند. دکمه‌ها هم با همان فهرست مجاز بررسی می‌شوند.

## عیب‌یابی

- **جوابی نمی‌دهد**: بررسی کن شناسه چت در **Admin Chat IDs** باشد. شناسه گروه منفی است، پس علامت منفی را هم کامل کپی کن.
- **پیام تست ارسال نمی‌شود**: توکن، Proxy URL و عضویت ربات در گروه با اجازه ارسال پیام را بررسی کن.
- **پیام‌ها به جای درست می‌روند**: گزینه فوروم و Topic ID آن مقصد را بررسی کن.
